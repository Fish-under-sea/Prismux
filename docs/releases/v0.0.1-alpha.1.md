# Prismux v0.0.1-alpha.1 发布说明（首个公开内测版）

> **发布日期**：2026-11-23 · **版本状态**：Pre-release（`v0.0.1-alpha.1`） · **内核许可**：MIT

`v0.0.1-alpha.1` 是 Prismux 的首个公开内测发行版，完整交付 M1–M5 全栈架构能力、Windows 桌面安装包与便携版、软件内国内外双网络自动切换更新系统，以及独立分发的四大官方可选插件。

---

## 核心特性与交付亮点

- **极简内核零预装原则**：桌面安装版与便携版均只包含 Prismux 极简高效内核（Tauri v2 透明壳 + 24h Daemon + React 19 Workbench UI + 单文件 SQLite 记忆中枢），**四大官方独立插件默认绝不预装**，安装完成后按需在插件市场手动安装。
- **双分发形态（Setup EXE + Portable ZIP）**：
  - **完整安装版**：`Prismux-Setup-0.0.1-alpha.1.exe`（NSIS 静奢 5 步安装向导，默认用户级安装至 `$LOCALAPPDATA\Prismux`）。
  - **零残留便携版**：`Prismux-Portable-0.0.1-alpha.1-win-x64.zip`（随附空 `data/` 目录与 `PORTABLE_MODE.txt`，运行态 SQLite 数据库、日志与 `0600` 插件凭据全部收敛于 `data/` 内，不在系统用户目录写任何残留）。
- **国内外双网络自动切换更新系统**：
  - 主程序内置 `AppUpdater`，支持「自动探测（推荐）/ 国内镜像优先 / 国际直连优先」三态路线，自动在 **GitHub Releases ↔ Gitee Releases** 间并发测速或故障回退；
  - 下载过程强制校验伴随的 64 位 `.sha256` / `SHA256SUMS.txt` 摘要（缺摘要或 1 字节篡改直接拒绝并清理 `.part` 临时文件），支持 `Range` 断点续传与用户可选自填加速前缀；
  - 插件市场第二轨同步支持在 **`registry.npmjs.org` ↔ `registry.npmmirror.com`** 间自动探速优选与故障回退，保持免本机 Git 与禁用生命周期脚本安全红线。
- **全栈能力齐备**：代理无关主秘书槽位（`Chief Thread Slot`）+ 只读 `vendor/t3code` 桥接、五大标杆原语（`PersistentPtyPool` / `HandoffEngine` / `CollectorAndGuard` / `LifecycleHookBus` / `WorktreeSandbox`）、`_callerScope` 物理防泄密三域记忆、360° Fresnel 液态玻璃与天体三态胶囊、`WebWallGL` 遮挡 `0 FPS` 挂起，以及 `OvernightFactory` 夜间全自动工场。

### 插件安装方式

1. **内置插件市场（推荐）**：打开 Prismux →「插件市场」→「官方认证区」按需一键安装；或在「第三方与 npm 导入」直接输入 `prismux-plugin-<id>`（自动按网络策略在 `npmjs` / `npmmirror` 间切换）。
2. **命令行提取 `.wb-plugin`**：

```powershell
# 国际源
npm install prismux-plugin-qq@0.0.1-alpha.1
npx prismux-plugin-qq --out ./plugins-stage

# 国内镜像源（npmmirror）
npm install prismux-plugin-qq@0.0.1-alpha.1 --registry=https://registry.npmmirror.com
npx prismux-plugin-qq --out ./plugins-stage
```

## 升级与安全提示

- 手动下载或软件内自动更新均受 `SHA256SUMS.txt` 与单个 `.sha256` 校验文件保护；如在命令行手动验证，可执行 `Get-FileHash .\Prismux-Setup-0.0.1-alpha.1.exe -Algorithm SHA256` 对照核验。
- 本版本为公开内测版（`0.0.1-alpha.1`），建议多端同步用户先导出一次 `.prismux-backup` 离线加密备份后再升级体验。
