## 二、本仓工具链

| 工具 | 路径与版本 | 用途与备注 |
| :--- | :--- | :--- |
| PowerShell / Shell | | 默认推荐 `pwsh` 7+ |
| Node（常规 / TS 脚本 / 测试） | | 要求 `>= 24.12.0`（支持原生 TS 运行 `scripts/*.ts`） |
| Node（大包发布备用版） | | 规避部分机器 Node 24 大 buffer zlib 异常（如 Node 22 LTS；无异常可填「同常规版」） |
| pnpm | | 要求 `>= 10.0.0`，建议匹配根 `packageManager`（`12.3.4`） |
| Rust / Cargo（M4 Tauri v2） | | 要求 `>= 1.85`（`rustc` / `cargo` 路径与版本；未装填「未装，M1–M3 暂不需」） |
| Git / GitHub CLI | | `git`、`gh` 路径与版本；`gh` 可注明已登录账号名（仅账号名，勿写令牌） |

## 三、环境变量与包缓存目录

| 变量 / 目录 | 建议值或路径 | 说明 |
| :--- | :--- | :--- |
| `pnpm` Store 目录 | | 可写入的 pnpm content-addressable store 路径 |
| `npm_config_cache` | | npm 缓存目录（避免默认用户目录受限报 `EPERM`） |
| `RUSTUP_HOME` | | 自定义 Rustup 目录（默认 `~/.rustup`） |
