# Prismux v0.2.0-RC.1 迭代计划（次日大版本施工清单）

> 记录时间：2026-11-24（主人拍板归入下一大版本 **`Prismux v0.2.0-RC.1`** / `0.2.0-rc.1`，待 `Prismux v0.1.3-Preview.3` 发版完成后按本清单执行）

## 一、智能体提供方与模型列表拖拽排序 + 原生纳入 `dsh`

### 1. 智能体提供方列表拖拽排序与全局同步（对应图一）
- 在 **设置 → 智能体提供方** 左侧列表中，为各提供方行（如 `Codex`、`Claude`、`Antigravity`、`Pi` 等）加入基于 `@dnd-kit/sortable` 的**拖拽调整顺序**能力，配备顺滑流畅的拖动动效（平滑位移过渡、拖拽浮起态阴影与放置高亮指示，单击选中零误触）。
- 排序结果持久化，并作为全局唯一真源**同步驱动软件外部所有展示提供方顺序的位置**（包括聊天输入框模型选择器顶部的常驻纯 Logo 切换条、新建标签/分屏代理选择、主秘书提供方列表、快捷启动菜单等）。

### 2. 原生支持列表调整：纳入 `dsh`，将 `Cursor` 移至下方
- 将 **`dsh`** 纳入 Prismux 原生一级支持提供方列表（开工前核实本机 `dsh` CLI 命令、ACP/会话协议、默认图标与模型发现方式，确保开箱即用）。
- 将 **`Cursor`** 下沉至下方「更多/折叠提供方」区，把原位置留给 **`dsh`**。

### 3. 模型列表拖拽排序与全局同步（对应图二）
- 在单个提供方的**模型列表**中，在保留现有 `↑ / ↓` 调整按钮或统一整合的前提下，新增丝滑的**拖拽调整模型顺序 + 拖动动效**。
- 模型顺序持久化，并**全局同步至所有外部模型选择入口**（主输入框模型选择器弹层、快捷键 `Ctrl+1..9` 绑定顺序、旁路提问模型选择器、主秘书模型列表等）。

## 二、三大工作面板 Toggle 关闭与视觉美化重构（对应图三）

针对左侧主导航栏的以下三个入口：
1. **任务面板**（`/tasks`）
2. **工作区板**（`/workspace-board`）
3. **定时任务**（`/automations` / `/scheduled-tasks`）

需完成两项核心升级：
- **原按钮双向切换（Toggle）**：当已处于任一面板时，**再次点击左侧对应原按钮即可直接关闭该面板并返回先前的主会话视图**（在展开侧栏与 `54 px` 收起态图标导轨下保持完全一致的 Toggle 交互）。
- **视觉层级与 UI 美化重排**：对照 [`docs/specs/ui-ux-design-mandate.md`](../specs/ui-ux-design-mandate.md) 重构这三个面板的信息架构、卡片层次、顶栏操作布局、筛选控件、空态引导与 6 分区液态玻璃适配（浅色 / 深色 / 浅色玻璃 / 深色玻璃全态高对比度且清爽克制）。

## 三、设置 → 外观 → 界面精简与推理强度默认值升级（对应图四）

- **删除「对比度」**（`setting-appearance-contrast`）：与 Prismux 外观保真度/对比度体系重复，去重删除，并同步清理 `settingsSearch.ts` 与测试。
- **删除「聊天宽度」**（`chat-width`）：移除该冗余下拉项，保持默认最优阅读宽度，并同步清理 `settingsSearch.ts` 与测试。
- **推理强度显示（`effortDisplay`）默认改为「条形（`bars`）」**：将 `DEFAULT_UNIFIED_SETTINGS.effortDisplay` 默认值由 `"label"`（名称）切换为 `"bars"`（条形信号），并同步检查重置按钮与旧测试断言。
