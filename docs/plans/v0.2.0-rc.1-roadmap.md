  - **项目标题行**：紧凑 `[项目图标 / 文件夹图标] [加粗项目名]`。
  - **工作区 / 分支卡片组**：同一工作区（或 worktree 分支）下的多条 Agent 会话聚合进同一紧凑圆角块内：
    - 工作区头行：`[状态圆点/旋转环] [工作区名]` + 主工作区展示 `[primary]` / `[主工作区]` 轻徽标；

  - **工作区下紧凑单行会话条目（约 `24–26 px` 单行高）**：
    `[微型状态环 / 绿勾] [Agent 厂商 Logo] [截断会话标题…]` —— 右对齐紧贴 —— `[规范化模型简称] [紧凑相对时间：now / 49m / 3h / 6h]`。

### 2. 模型显示名称精准过滤与大小写规范化
- **要求**：在侧边栏会话行（及全站所有展示模型简称的位置）统一过滤冗长厂商前缀与小写连字符 slug，执行规范大写与精炼呈现：

### 3. 会话标题强制简体中文 + 每轮对话结束后自动总结更新 + 用户自定义锁
- **强制中文总结**：升级 `vendor/t3code/packages/provider-core/src/server/textGenerationPrompts.ts` 中的 `initialThreadTitlePrompt` 与 `regenerateThreadTitlePrompt`，明确要求输出精炼、准确的**简体中文短语标题**（保留必要专有名词如 `GitHub`、`Electron`、`OAuth`、`API`，禁止输出整句英文、末尾标点或机械截断用户原话）。
- **每轮结束后自动总结更新**：目前 `vendor/t3code/apps/server/src/orchestration-v2/Orchestrator.ts`（约 `L7428–L7466`）仅在首次发送消息（`seedsUntitledThread`）时派发 `initial` 标题生成。改造为在**每轮 Agent 回复正常完成后**（非子代理、非纯系统维护命令），异步派发一次 `ThreadTitleRegenerationService`（`kind: { type: "regenerate" }`，带并发去重/防抖，零阻塞主对话），根据最新完整对话主题持续提纯更新会话标题。
- **用户自定义命名永久锁定**：严格尊重已有 `thread.titleRenamed === true` 标记（用户手动重命名时在 `Orchestrator.ts:5109` 写入 `titleRenamed: true`）；一旦用户自定义过会话名称，后续轮次结束**绝不再自动触发总结或覆写**。
