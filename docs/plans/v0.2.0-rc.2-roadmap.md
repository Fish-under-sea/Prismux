## 四、底部状态栏额度动态显隐 + 服务体检隐藏未安装 AI Provider CLI（`media_1795594852350_253b333e.png`、`media_1795595617002_7e9a6645.png`）

### 1. 底部状态栏额度改为「实时按登录态动态显隐」
- **痛点**：底栏额度区不能常态硬显占位，没登录对应提供方账号时绝不应展示该账号（或空壳 `0%` / 失效额度条）。
- **改造方案**（`vendor/t3code/apps/web/src/prismux/statusBar/quotaStatus.logic.ts`、`PrismuxStatusBar.tsx`、`QuotaStatusPopover.tsx`、`apps/daemon/src/system/OfficialQuotaService.ts`）：
  1. **按登录态实时过滤**：仅当对应提供方处于**已启用且实时检测已登录并拿到有效额度**时才在底栏渲染该提供方段；某提供方未登录、已登出或被禁用时**实时从底栏隐藏**（不展示 `0%` 占位或“未登录”噪音）。
  2. **全部未登录时完全隐藏底栏额度组件**：当没有任何已登录且支持额度查询的账号时，底栏不占据任何常驻位置；一旦任一账号完成登录（或点击刷新/切回前台检测到新登录态），实时自动浮现。
  3. **登出即时清缓存**：检测到登出/失效态时立即清除对应内存缓存，防止残留旧百分比。

### 2. 服务体检「AI Provider CLI」隐藏未安装项，仅对已安装但异常/无法启用项标「降级」
- **痛点**（`media_1795595617002_7e9a6645.png`）：目前未安装的可选 CLI（如 `Gemini CLI`、`OpenCode CLI` 以及待删的 `Oh My Pi CLI (omp)`）全被标为黄色「降级」卡片并触发侧栏「服务体检」常亮黄点，误导用户以为环境坏了。
- **改造方案**（`apps/daemon/src/system/ServiceDiagnosticsService.ts`、`vendor/t3code/apps/web/src/prismux/settings/PrismuxDiagnosticsSection.tsx`、`prismuxDiagnostics.logic.ts`、`useLiveDiagnosticsBadgeTone.ts`）：
  1. 彻底移除 `Oh My Pi CLI (omp)` 探针；纳入本机 `dsh`（DeepSeek Harness CLI）探针。
  2. **未检测到安装的 AI Provider CLI 不在服务体检列表中显示，也不计入任何降级/告警计数**（不点亮侧栏黄点）。
  3. **仅当对应 CLI 已安装在本机，但无法启动、版本探测报错或运行异常需要修复时，才显示为「降级」卡片**（已安装且运行正常则显示为「正常」）。
